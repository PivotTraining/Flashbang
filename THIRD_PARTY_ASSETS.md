# Third-party assets

Flashbang uses the following public-domain (CC0 1.0) art sources in the current web prototype.

## Quaternius — Universal Base Characters

- Used for the real skinned humanoid fighter (`Superhero_Male_FullBody` / `night-striker.glb`).
- Original creator: Quaternius.
- License: CC0 1.0 Universal / public domain.
- Runtime browser conversion currently pinned from `Seyamalam/blood-league-kickoff` commit `aa02a4e6d8337a0604d2da131bcbbeb1f01badf0`.
- Runtime path: `public/assets/vendor/quaternius/night-striker.glb`.

## Quaternius — Universal Animation Library

- Used for skeletal locomotion, punch/kick, spell/energy and hit-reaction animation clips.
- Original creator: Quaternius.
- License: CC0 1.0 Universal / public domain.
- Runtime browser conversion currently pinned from `Seyamalam/blood-league-kickoff` commit `aa02a4e6d8337a0604d2da131bcbbeb1f01badf0`.
- Runtime path: `public/assets/vendor/quaternius/universal-animation-library.glb`.

## Quaternius — Stylized Nature MegaKit

- Textured trees used around Thunder Summit.
- Original creator: Quaternius.
- License: CC0 1.0 Universal / public domain.
- Web-optimized GLBs currently pinned from `anshaneja5/skyline-run` commit `0c41526d8d4130c37c15e219c2c3737fa8cb4ad8`.
- Runtime paths: `tree1.glb`, `tree2.glb`, `tree3.glb`.

## Quaternius — Downtown City MegaKit

- Textured architecture used for Thunder Summit's distant citadel/skyline layer.
- Original creator: Quaternius.
- License: CC0 1.0 Universal / public domain.
- Web-optimized GLBs currently pinned from `anshaneja5/skyline-run` commit `0c41526d8d4130c37c15e219c2c3737fa8cb4ad8`.
- Runtime paths: `b_small.glb`, `b_medium.glb`, `b_large.glb`.

These assets are pinned to immutable upstream commits so the deployed game does not silently change if a source repository's main branch changes. Flashbang's own characters, visual identity, game rules, stage composition, effects, UI, code, and gameplay remain project-specific work built around these public-domain base assets.
